# libp2p-raft Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a learning DIY mini-Raft `NetworkBehaviour` for rust-libp2p with a pure `RaftEngine`, custom unary stream protocol, in-memory storage, and a working 3-node example.

**Architecture:** `RaftEngine` is a synchronous state machine (tick / handle_rpc → Actions). `RaftBehaviour` owns the engine, `PeerMap`, `PendingRequest` map, and a deadline `Sleep`; it maps Actions to `ConnectionHandler` framed RPCs on `/libp2p-raft/1.0.0`. Consensus logic never imports libp2p types.

**Tech Stack:** rust-libp2p (tokio), serde + bincode, futures, thiserror, tracing, Edition 2021

**Spec:** `docs/superpowers/specs/2026-07-23-libp2p-raft-design.md`

## Global Constraints

- DIY Raft only — do not depend on OpenRaft / raft-rs / async-raft
- Custom stream + `ConnectionHandler` — do not use `request_response` for Raft RPCs
- `Storage::persist` is the only write path for hard state + log appends (atomic batch)
- Replication reject handling: simple `next_index` decrement (no conflict hints)
- Tick: Behaviour deadline Sleep; call `engine.tick(now)` only when due
- Membership: `AddNode` XOR `RemoveNode` one at a time; reject while pending
- Snapshot failure: restart from offset 0
- Pin keypairs in examples; static `seed_peers: Vec<(NodeId, PeerId, Multiaddr)>`
- Comments and commit messages in English
- TDD: failing test → implement → pass → commit per task

```rust
use crate::error::Error;
use crate::protocol::messages::WireEnvelope;
use byteorder::{BigEndian, ReadBytesExt, WriteBytesExt};
use std::io::Cursor;

pub fn encode_envelope(env: &WireEnvelope) -> Result<Vec<u8>, Error> {
    let payload = bincode::serialize(env).map_err(|e| Error::Codec(e.to_string()))?;
    let mut out = Vec::with_capacity(4 + payload.len());
    out.write_u32::<BigEndian>(payload.len() as u32)
        .map_err(|e| Error::Codec(e.to_string()))?;
    out.extend_from_slice(&payload);
    Ok(out)
}

pub fn decode_envelope(bytes: &[u8]) -> Result<WireEnvelope, Error> {
    let mut cur = Cursor::new(bytes);
    let len = cur
        .read_u32::<BigEndian>()
        .map_err(|e| Error::Codec(e.to_string()))? as usize;
    let start = cur.position() as usize;
    let end = start + len;
    if bytes.len() < end {
        return Err(Error::Codec("truncated".into()));
    }
    bincode::deserialize(&bytes[start..end]).map_err(|e| Error::Codec(e.to_string()))
}
```

Add `byteorder = "1"` to `Cargo.toml` dependencies.

- [ ] **Step 1: Integrate engine into Behaviour**

In `poll`:

1. Drain handler events; match `correlation_id`; `engine.handle_rpc` / ignore stale term
